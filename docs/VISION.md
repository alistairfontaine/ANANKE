# THE TAO OF ANANKE: PROJECT VISION

## 1. The Antidote to Learned Helplessness
Modern software engineering has fallen victim to dependency addiction. Developers believe that to simulate a quantum state, compute a tensor product, or manage complex numbers, they must pull down hundreds of megabytes of third-party packages, abstraction layers, and runtime environments. This is a manifestation of learned helplessness.

`ANANKE` rejects this completely. By writing the math ourselves, we regain total mastery over the silicon.

## 2. Hard Iron Principles
*   **Zero Dependencies:** The standard library (`<vector>`, `<complex>`, `<cmath>`) is all we need.
*   **Deterministic Clarity:** Quantum mechanics is probabilistic, but simulating it is a game of pure linear algebra. The engine must be readable, lean, and brutally efficient.
*   **Computational Liberty:** Anyone with a basic laptop, a text editor, and a standard compiler should be able to run high-level quantum simulations without enterprise permission.
